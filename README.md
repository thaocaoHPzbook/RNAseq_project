
# RNAseq_project

This repository contains the RNA-seq data and analysis workflow used for transcriptomic analysis.

## Data source

The dataset used in this analysis was obtained from the RNA-seq data reported in the study:

> **Comprehensive transcriptome analysis of neocortical layers in humans, chimpanzees and macaques**

published in *Nature Neuroscience* in 2017.

The data used in this project are derived from the RNA-seq dataset associated with this publication.


*Nature Neuroscience* (2017).

[Publication](https://www.nature.com/articles/nn.4548)
